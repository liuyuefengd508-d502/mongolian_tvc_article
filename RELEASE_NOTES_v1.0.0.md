# Initial public release for TVC resubmission

This release is directly related to the manuscript submitted to *The Visual Computer*:

**Unsupervised Domain Adaptation for Vertical Cursive Script Recognition with Geometric Stroke Enhancement and Pseudo-Label Refinement**

## Included in this release

- manuscript sources and compiled submission materials
- response-letter draft for the current revision cycle
- lightweight research code and supporting scripts
- public figures and reproducibility metadata
- GitHub citation metadata and Zenodo archive metadata

## Not included

- full restricted archival dataset
- large trained weights
- heavy experiment output directories

The complete authentic archival dataset is subject to institutional and cultural-heritage access restrictions. This release therefore provides code, manuscript materials, figures, protocol descriptions, and lightweight public artifacts only.
