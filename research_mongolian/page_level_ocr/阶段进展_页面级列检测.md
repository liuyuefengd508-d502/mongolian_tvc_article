## 当前目标

本阶段目标是把传统蒙古文历史档案 OCR 从“人工裁好的孤立文本列识别”推进到“整页图像中的文本列检测与阅读顺序恢复”。当前工作重点是 8 页验证集和 11 页测试集的页面级列框标注、自动列检测评估和 hard case 优化。

YOLO 阅读顺序恢复策略：

- 默认页面：按检测框列中心从左到右排序。
- 旋转重标页：若 `image_path` 中包含 `rot90`，按列中心从右到左排序。
- 该策略只改变 `reading_order`，不改变检测框坐标，因此不影响 Precision、Recall、F1 和 Mean IoU。

## 关键改进记录

1. `80-48-74-2` 旋转重标后，人工 GT 更合理，但原 proposed 仍将多个稀疏文字段合成长列。

2. 初版基于 Sauvola 二值图的纵向切段副作用很大，整体 F1 从 0.621 降到 0.320，因此已撤回。

3. 改用暗墨迹掩膜后，只在特殊页触发，`80-48-74-2` 从：

```text
F1: 0.158 -> 0.370
TP: 3 -> 10
FN: 19 -> 12
```

4. 阅读顺序优化后，整体 reading-order accuracy 从：

```text
0.699 -> 0.839
```

其中 `80-48-74-2` 从：

```text
0.022 -> 0.978
```

5. 加入 `score >= 0.30` 置信过滤后：

```text
Val F1: 0.637 -> 0.732
Test F1: 0.449 -> 0.562
```

6. 加入低置信强列候选恢复后：

```text
Val F1: 0.732 -> 0.732
Test F1: 0.562 -> 0.582
Test TP: 79 -> 83
Test FP: 39 -> 39
Test FN: 84 -> 80
```

该规则只恢复 `score` 在 0.18 到 0.30 之间、宽度和高度符合文本列先验、宽高比不过大，并且框内墨迹密度、行覆盖率和列覆盖率均达到阈值的候选框。它的作用是小幅补回短列、淡墨列，不改变主干检测流程。

7. 已尝试“长框按暗墨迹纵向间隔二次切分”，但暂不纳入默认方法。

该策略能明显改善测试页 `80-48-73-1`：

```text
80-48-73-1 F1: 0.194 -> 0.372
TP/FP/FN: 3/8/17 -> 8/15/12
```

但它会明显伤害多数正常页面，尤其是验证集中的长列页面：

```text
80-48-67-6 F1: 1.000 -> 0.444
80-48-67-7 F1: 0.800 -> 0.303
80-48-74-2 F1: 0.526 -> 0.281
80-48-78-3 F1: 0.750 -> 0.516
```

结论：长框切分不是稳定的全局后处理，只适合在页面类型判别可靠后作为 hard-case 分支使用。当前默认结果仍保留低置信恢复版本。

## 当前不足

1. 测试集 F1 仍低于验证集。
   测试集 F1 为 0.582，说明泛化仍有不足。主要问题集中在 `80-48-73-1`、`80-48-70-1`、`80-48-62-1(1)` 等页面。

2. 自动框与人工框粒度不一致。
   低分页中常见问题不是完全没有候选，而是自动方法把上下多个短文本段合并成一条长框，导致 IoU 低于 0.5。例如 `80-48-73-1` 中多处人工短框被一个长自动框覆盖，评价时仍计为 FN/FP。

3. Recall 偏低。
   置信过滤和低置信恢复后，test recall 提升到 0.509，但短列、淡墨列和复杂区域仍存在漏检。

4. 个别页面标注粒度和 ignore 策略需要复核。
   例如 `80-48-73-1` 和 `80-48-65-1(2)` 中存在较多 ignore 或复杂区域，容易影响自动检测评估。

5. 当前优化仍是规则法。
   规则法可解释性强，但对复杂纸张褶皱、稀疏短列和多区域文本不够稳。论文中应将其定位为可解释页面级 baseline 或轻量 layout-aware pipeline。

## 下一步建议

1. 优先分析测试集低分页。
   重点查看 `80-48-73-1`、`80-48-70-1`、`80-48-62-1(1)` 的调试图，区分漏检、ignore 区域干扰和标注粒度差异。

2. 增加页面类型判别。
   当前长框切分对 `80-48-73-1` 有效，但对多数页面有害。下一步需要先判断页面是否属于“多段短文本/长框过合并”类型，再触发切分分支。可考虑的判别特征包括：
   - 高置信长框数量
   - 长框内部垂直投影断裂数
   - 页面内短 GT 或短候选比例
   - 文本区域是否集中在上下多个分离带

3. 增加漏检恢复。
   重点继续恢复短列、淡墨列和被强过滤删除的真实文本列。当前低置信候选恢复只带来小幅收益，后续可以尝试：
   - 暗墨迹连通性
   - 笔画宽度统计
   - 框内暗像素列投影峰值数量
   - 轻量学习式列检测器，作为规则法的 stronger baseline

当前已完成 YOLO 数据集导出，下一步可以直接训练一个小型检测模型，先验证学习式方法能否缓解长框过合并和短列漏检问题。
目前 20 epoch 和 50 epoch 试跑都显示学习式方法已有可行性，但 test recall 仍低于规则法，因此下一步重点不是替换 proposed，而是扩充训练页并把 YOLO 作为 stronger baseline 继续发展。
